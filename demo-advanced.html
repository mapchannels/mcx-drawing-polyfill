mcx-drawing-polyfill v2 — Advanced Marker Mode

The Maps API on this page is loaded with libraries=marker and the map is created with a mapId, so markerType: 'auto' resolves to advanced google.maps.marker.AdvancedMarkerElement. The marker tool drops a custom HTML pin (markerOptions.content, cloned per marker), and the polyline/polygon finishing node is a custom SVG diamond (finishingMarkerSVG) — click it to finish a shape. Marker positions in the output are read via MCXMarkerUtils.getLatLng(), which works for both marker classes.
