mcx-drawing-polyfill v2 — Basic Marker Mode

The Maps API on this page is loaded without libraries=marker and the map has no mapId, so markerType: 'auto' resolves to basic google.maps.Marker. All five tools are available: click to place markers and draw lines/polygons (click the white node to finish), and press and drag for circles and rectangles (panning is locked while those tools are active). Custom polylineOptions, polygonOptions and ghostlineOptions are set below — note the in-progress line and the dotted preview match the finished shape's styling.
